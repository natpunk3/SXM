# SXM
Ever wanted to stream SXM through VLC or your terminal?

![alt text](https://github.com/natpunk3/SXM/)

# Installation
1. pip install sxm
2. git clone https://github.com/natpunk3/SXM && cd SXM
3. Edit go-sxm & list-sxm and add your Sirius XM Username and Password.
Then run the programs from there!
